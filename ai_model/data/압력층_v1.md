# HY-MATCH 압력층 v1 (클립 힘 ↔ 귓불 두께, FSR 채널)

작성 2026-10-18 · 짝 코드: `pressure_layer_v1.py`, `pressure_params_v1.json`, `run_pressure_v1.py` (numpy만) · 자체 검사 83개 통과 · 통합 모델과 GUI 검사 85개 통과 · 상태: **시뮬레이션. 실측으로 검증되지 않았습니다.**

이 문서의 숫자는 모두 코드가 계산한 값이고, 같은 폴더의 `run_pressure_v1.py`를 다시 돌리면 그대로 나옵니다(약 10초). **클립이 귓불을 누르는 힘, 클립 스프링의 세기, FSR의 저항–힘 곡선은 아직 아무도 측정하지 않았습니다.** 이 값들은 가정이고(`pressure_params_v1.json`에 ‘근거’ 표시), 측정하면 그대로 바꿔 넣을 수 있습니다.

## 1. 한 줄 요약

클립을 스프링으로, 귓불을 힘에 비례해 눌리는 층으로, FSR402를 분압 회로로 ADS1115에 붙인 모델입니다. FSR은 하중이 지나가는 길목에 있으므로 FSR이 읽는 힘이 곧 귓불에 걸린 힘이고, 클립의 ‘힘–틈’ 곡선(스프링 법칙)을 알면 읽은 힘에서 두께(틈)를 환산할 수 있습니다. 이 환산의 오차를 데이터시트 값으로 계산하고, 혈당 오차에 미치는 영향을 통합 모델로 확인했습니다.

- **FSR로 읽은 두께의 1σ 오차는 약 0.12 mm입니다**(공칭 틈 4.0 mm, 착용 30분 시점). 기존 가정 0.05 mm의 약 2.5배입니다. 틈이 3.5 mm이면 0.08, 4.5 mm이면 0.16 mm입니다.
- **오차는 ‘힘의 상대 오차 × (두께 − 영힘 틈 g0)’입니다.** 힘의 상대 오차가 8.2 %이고 g0 = 2.5 mm이므로 4.0 mm에서 0.082 × 1.5 = 0.12 mm입니다. 스프링을 세게 만들어도 오차는 그대로이고, **스프링이 얼마나 눌려 있는가(g0가 두께에 얼마나 가까운가)가 정합니다.**
- **가장 큰 항은 FSR의 시간 드리프트입니다**(데이터시트: 10배 시간마다 5 % 미만). 착용 30분 시점의 힘 오차 8.2 % 중 드리프트가 7.4 %입니다. 착용 1분 시점에 읽으면 0.053 mm, 5분 0.074, 120분 0.165, 480분 0.208 mm입니다. ADC 잡음은 21 µN으로 무시할 수 있습니다.
- **그런데 혈당 오차는 거의 변하지 않습니다.** 융합 + 보정의 혈당 1σ가 두께 센서 없음 12.48, 가정값 0.05 mm 12.48, FSR 모델 12.48 mg/dL입니다. 이유는 NIR·마이크로파 읽기값 자체가 두께를 이미 µm 단위로 정하기 때문입니다(융합 0.8 µm, NIR만 2.0, 마이크로파만 2.5 µm). 두께 센서가 도움이 되려면 오차가 0.01 mm보다 작아야 하고(12.46), 0.001 mm쯤 돼야 눈에 띕니다(11.44 mg/dL). 모델이 모르는 교란(산란, 수분, 공기 틈 등)이 있을 때의 혈당 편향도 같습니다(10절).
- **Kim 2025의 착용 중 두께 변화(5명)를 이 모델에 넣으면 클립 틈 변화는 -0.30 ~ +0.03 mm, 힘 변화는 k × 틈 변화(k = 1 N/mm이면 같은 숫자의 N)입니다.** 힘 오차 0.12 N과 비교하면 V3, V5(신호/잡음 2.4, 2.0)만 알아볼 수 있고, 나머지는 0.08~0.5배라 묻힙니다. FSR은 두께를 정밀하게 재는 센서가 아니라 **클립이 얹혀 있는지, 크게 눌리거나 움직였는지를 보는 감시 센서**로 쓰는 것이 이 모델의 결론입니다(Kim 2025도 NFSR을 움직임 지표로 썼습니다).
- **가장 얇은 귓불(2.7 mm)에서는 힘이 0.19 N**이라 FSR402의 최소 작동력 0.2 N 아래입니다(이 가정의 클립 기준). 영힘 틈 g0를 낮추면 얇은 귓불도 읽지만 오차가 커지는 맞교환이 있습니다(8절).

## 3. 모델

**클립(스프링).** 틈 g에서 귓불에 주는 힘 F = F_nom + k (g − g_nom), 영힘 틈 g0 = g_nom − F_nom / k 아래에서는 0. F_nom = 1.5 N(공칭 틈 g_nom = 4.0 mm에서의 힘), k = 1.0 N/mm는 **가정**이고 g0 = 2.5 mm입니다.

**귓불.** 힘 F에서 두께 = d_free (1 − c F), c = (공칭 힘에서의 변형률) / F_nom. 공칭 변형률 3.4 %는 Kim 2025 다섯 명의 평균 압축(+0.27 ~ +8.72 %와 한 명의 −0.74 %)에서 따온 **크기 감각**입니다. d_free는 클립이 공칭 틈에 앉는 이완 두께(4.14 mm)가 기본이고, 사람마다 다릅니다(Kim: 16명 평균 3.91, 2.7~4.8 mm). 이 선형 모델에서 귓불의 강성은 약 11 N/mm로 클립 스프링(1 N/mm)보다 훨씬 단단합니다.

**평형.** 클립이 미는 힘 = 귓불이 되미는 힘이 되는 (틈, 힘)을 구합니다. 얇은 귓불은 틈도 힘도 작아집니다(Kim: 얇은 귓불은 접촉 압력이 낮다). 귓불이 영힘 틈보다 얇으면 닿지 않아 힘이 0입니다.

**FSR 채널.** FSR402를 Vcc(3.3 V)에, 고정 저항 R_M(10 kΩ)을 접지에 놓은 분압(힘이 늘면 전압이 오름). 전도도 G = G_ref (F / 9.81 N)^n, G_ref = 1/4.6 kΩ(Interlink 적분 가이드의 ‘전형적인 FSR’ 예, 1 kg), n = 1.0. ADS1115의 범위 선택과 잡음은 노이즈 층 것을 그대로 씁니다. 분압 결과: 힘 1.5 N에서 FSR 30.1 kΩ, 전압 0.82 V.

**두께 읽기.** 읽은 힘 F̂에서 ĝ = g_nom + (F̂ − F_nom) / k. 클립 전체(FSR + 스프링)를 틈 게이지로 한 번 교정하면 FSR의 눈금 오차(부품 간 ±6 %)는 F̂와 k에 똑같이 들어가 사라집니다(`calibrated_per_unit`).

**두께 읽기 오차(1σ).** 힘에 비례하는 항을 제곱합으로 합칩니다.

| 항 | 값 | 출처 |
|---|---|---|
| ADC 잡음 | σ_V ÷ (dV/dF) (평균 50회) | ADS1115 데이터시트(노이즈 층) |
| 반복성 | 2 % × F | FSR 400 데이터시트: 단일 부품 ±2 % (한계값을 1σ로 사용) |
| 히스테리시스 | 2.9 % × F | 데이터시트: +10 %. 올릴 때와 내릴 때의 차이이므로 ±5 % 균일 분포로 보고 5 %/√3 |
| 드리프트 | 5 % × log10(착용 시간 / 교정 시간) × F = 7.4 % × F (30분) | 데이터시트: 10배 시간마다 5 % 미만. 부호를 모르므로 1σ처럼 취급 |
| 부품 간 편차 | 0 (부품별 교정) 또는 6 % × F | 데이터시트 ±6 % (단일 로트) |
| 스프링 교정 | 절댓값(g − g_nom) × 3 % | 틈 게이지 교정으로 구한 k의 오차(가정) |

앞의 네 항은 힘 오차이고 k로 나눠 두께로 바꿉니다. 그 결과 σ = (상대 오차) × F / k = (상대 오차) × (g − g0) + (스프링 교정 항)입니다. 데이터시트 값은 ‘한계’인 경우가 많아 1σ로 쓰면 보수적입니다.

**통합 모델에 연결.** `IntegratedModelV1(pressure=True)`이면 ‘융합 + 보정’의 두께 센서 σ가 위 값이 됩니다(두께에 따라 달라짐). 읽기값에는 σ만큼의 정규 잡음을 더하고, 추정기에는 **읽은 두께에서의 σ**를 알려 줍니다(참 두께는 모르므로). 기본은 꺼져 있어(`pressure=None`) 이전 문서의 숫자는 그대로입니다. 힘이 FSR 작동 범위(0.2~20 N) 밖이면 σ가 무한대가 되어 그 읽기는 정보로 쓰이지 않습니다.

## 5. 검증

자체 검사 83개가 통과합니다(`test_pressure_layer_v1.py`, 2초). 기대값은 코드를 부르지 않고 이 파일 안에서 손으로 계산합니다.

- 클립 법칙(영힘 틈 2.5 mm, 4.2 mm에서 1.7 N), 귓불 법칙, 평형(세 가지 두께의 틈과 힘, 두 곡선이 같은 힘을 주는지), 닿지 않는 경우.
- 분압: 1.5 N에서 FSR 30.07 kΩ, 0.8235 V, dV/dF(해석식 = 수치 미분), 전압 → 힘 역변환(n = 1, 0.8), ADC 범위(고정 ±2.048 V, 자동 선택 시 ±1.024 V)와 잡음.
- 오차 예산: 반복성·히스테리시스·드리프트의 제곱합(0.1227 mm), 틈 4.5 mm의 스프링 교정 항, 착용 5분, 드리프트 제거, 부품 간 편차, 잡음 배율, ‘같은 g0이면 스프링 세기가 달라도 같은 σ’, 사용 불가 범위(0.2 N 미만)에서 σ = ∞.
- Kim 2025의 정의 p = 100 (후 − 전)/후에서 후/전 = 1/(1 − p/100), 다섯 명의 평균 압축 3.416 %, V3 사례의 틈·힘 변화.
- 시뮬레이션한 읽기 2만 번의 표준편차가 오차 예산과 3 % 안에서 같음(틈 3.7·4.0·4.5 mm), 평균 오차 0.
- 통합 모델 쪽 검사(`test_integrated_model_v1.py`, 전체 85개 중 압력 관련 17개): 기본값은 0.05 mm 그대로, 두께에 따라 σ가 변함, 직접 지정한 σ가 우선, 힘이 모자라면 σ = ∞인데도 추정이 유한, 몬테카를로 표준편차가 예상 오차와 일치, GUI의 힘·두께 슬라이더 연동과 스위치.

검사하지 않은 것: 이 숫자들을 실측과 비교하지 않았습니다. 코드가 ‘정한 식을 맞게 계산하는가’를 확인했고, 클립과 귓불이 이렇게 행동하는지는 확인하지 않았습니다.

## 11. 한계와 미검증

- **클립 힘, 스프링 상수, FSR의 저항–힘 곡선은 모두 가정입니다.** 결과의 숫자(0.12 mm 등)는 이 가정을 따라 움직입니다. 측정 방법은 12절에 있습니다.
- **선형 스프링, 선형 귓불, 정적 평형입니다.** 귓불은 점성탄성이라 시간에 따라 흐르고(Kim 2025: 움직임에 민감) 비선형입니다. 마찰, 경첩 히스테리시스, 클립의 기울어짐은 넣지 않았습니다.
- **압력이 광학에 주는 영향은 두께로만 넣었습니다.** 실제로는 눌리면 혈액이 빠져 흡수와 산란이 바뀝니다. 이 효과는 모델에 없습니다(Kim 2025는 정규화한 FSR 신호 NFSR을 Conv1D 입력 특징의 하나로 썼습니다).
- **Kim 2025의 두께 변화는 힘–변형 곡선이 아닙니다.** 게이지로 잰 전·후 두께 사이의 변화이고 힘 값이 없습니다. 크기 감각(몇 % 수준)으로만 썼습니다. 지원자 5명입니다.
- **데이터시트의 한계값을 1σ로 썼습니다**(반복성, 히스테리시스, 드리프트). 실제 편차는 이보다 작을 수 있습니다. 드리프트는 한 방향으로 흐르므로 부호를 알면 일부 보정됩니다.
- **FSR의 저항–힘 값은 ‘전형적 FSR’ 예(1 kg에서 4.6 kΩ)에서 가져왔습니다.** FSR402 데이터시트의 로그–로그 그래프 값이 아닙니다. 부품 간 차이가 큽니다(적분 가이드: ±15~25 %). 힘 오차 계산은 상대 오차 위주라 큰 영향이 없지만 분압 전압과 ADC 범위가 바뀝니다.
- **FSR은 면압에 민감하고 누르는 방식에 따라 읽힘이 달라집니다**(데이터시트: 측정은 눌러주는 구조와 회로에 따라 다름). 클립에서 FSR을 어디에 어떻게 얹느냐가 실제 오차를 좌우합니다.
- **통합 모델의 추정기는 산란·수분을 미지수로 두지 않습니다.** 그래서 두께 센서의 가치가 과소평가돼 있을 수 있습니다(10절).

## 13. 결정이 필요한 것

- **FSR을 두께 센서로 쓸지, 착용·움직임 감시로만 쓸지.** 이 모델의 결론은 후자입니다(혈당 정밀도에는 영향이 없고, 큰 압축이나 클립 이탈은 볼 수 있음). 그렇다면 ‘융합 + 보정’의 두께 센서 항은 정보가 없는 것으로 보고 `pressure=None`(가정 0.05 mm) 그대로 두어도 같은 결과입니다.
- **기본 두께 σ를 무엇으로 할지.** 지금 기본은 이전 문서와 같은 0.05 mm 가정이고, FSR 모델은 옵션입니다. 클립 측정 전에는 어느 쪽도 근거가 약합니다.
